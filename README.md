# Student Score Calculator
A simple web application using HTML, CSS, and JavaScript. It automatically calculates student totals and letter grades in real-time as scores are entered.

## Features

* Interactive table featuring 5 students.
* Input fields for **CA 1**, **CA 2**, **CA 3**, and **Exam**.
* Automatic calculation of **Total** scores.
* Automatic assignment of letter **Grades** (A to F) based on performance.

## Files Included

* `index.html` — The main structure and table layout
* `style.css` — The styling and design
* `script.js` — The JavaScript logic for calculations and grading

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in any web browser (Chrome, Firefox, etc.).
3. Type numbers into the score boxes to test the live updates.
